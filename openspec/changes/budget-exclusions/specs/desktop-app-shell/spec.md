# Spec Delta

## ADDED Requirements

### Requirement: Budget in the menu
The app navigation SHALL list «Budget» between «Regular payments» and «Planning». It SHALL open the budget screen,
show «Budget» as the screen's title and be the current entry while that screen is open.

#### Scenario: From any screen
- **WHEN** the user is on «Analytics» and picks «Budget» in the menu
- **THEN** the budget screen opens, titled «Budget», with «Budget» current in the menu
